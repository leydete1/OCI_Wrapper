Great 👍 since you’re targeting Oracle 23ai and building a general OCI wrapper, the best approach is to create a table that covers:

    All scalar SQL types

    Character + national character types

    Date/time types (including time zone variants)

Below is a clean, OCI-friendly test table and a matching insert.
1️⃣ Create Table: oci_field_test

CREATE TABLE oci_field_test (
    -- Numeric types
    number_col              NUMBER,
    number_p_s_col          NUMBER(10, 2),
    float_col               FLOAT,
    binary_float_col        BINARY_FLOAT,
    binary_double_col       BINARY_DOUBLE,

    -- Character types
    char_col                CHAR(10),
    varchar2_col            VARCHAR2(100),
    nchar_col               NCHAR(10),
    nvarchar2_col           NVARCHAR2(100),

    -- Date & Time types
    date_col                DATE,
    timestamp_col           TIMESTAMP,
    timestamp_tz_col        TIMESTAMP WITH TIME ZONE,
    timestamp_ltz_col       TIMESTAMP WITH LOCAL TIME ZONE,

    -- Interval types
    interval_ym_col         INTERVAL YEAR(4) TO MONTH,
    interval_ds_col         INTERVAL DAY(4) TO SECOND(6),

    -- Binary types
    raw_col                 RAW(50),

    -- LOB types
    clob_col                CLOB,
    nclob_col               NCLOB,
    blob_col                BLOB,

    -- Rowid types
    rowid_col               ROWID,
    urowid_col              UROWID
);

Notes for OCI testing:

    FLOAT is internally NUMBER — useful for testing describe behavior.

    BINARY_FLOAT / BINARY_DOUBLE test native IEEE bindings.

    TIMESTAMP WITH LOCAL TIME ZONE is normalized to DB time zone.

    ROWID and UROWID are useful for descriptor handling.

    LONG is intentionally excluded (deprecated and problematic in OCI).

    BFILE excluded unless you specifically need external LOB testing.

DECLARE
    v_blob  BLOB;
    v_bfile BFILE := BFILENAME('PHOTO_DIR','Adam_1.jpg');

BEGIN
    INSERT INTO OCI_LOB_TEST (id, DESCRIPTION , FILE_NAME , photo)
    VALUES (1, 'Adams pizza', 'Adam_1.jpg', EMPTY_BLOB())
    RETURNING photo INTO v_blob;

    DBMS_LOB.OPEN(v_bfile, DBMS_LOB.LOB_READONLY);

    DBMS_LOB.LOADFROMFILE(
        dest_lob => v_blob,
        src_lob  => v_bfile,
        amount   => DBMS_LOB.GETLENGTH(v_bfile)
    );

    DBMS_LOB.CLOSE(v_bfile);

    COMMIT;
END;
